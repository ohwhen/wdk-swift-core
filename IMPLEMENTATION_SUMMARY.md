## Architecture Philosophy

### Core Principle
**Runtime integration, not pure unit testing.**

The worklet + BareKit + addons form a runtime stack that requires:
- Actual iOS process
- File system access to bundles
- IPC communication channels
- Native framework loading

Attempting to unit test this with pure SwiftPM was the wrong approach.

### New Approach
1. **Swift package:** Pure wrapper logic only
2. **XcodeGen app:** Runtime integration and testing
3. **Pre-actions:** Automatic bundling on every build
4. **Starter example:** Working template for users

This matches how the reference implementation (wdk-wallet-swift-final) works and is proven to be reliable.
